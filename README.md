## 🧬 The Architecture of My Mind

I like building software all the way down: from product idea and UX to APIs, databases, native desktop behavior, deployment and the edge cases that only appear in production.

> **Idea → Architecture → UI → API → Data → Native Integrations → Deployment → Real Users → Iterate**

- ⚙️ **Root-Cause Engineering** — understand *why* before patching the symptom.
- 🧩 **Full-Stack Product Thinking** — frontend, backend, database, infrastructure and UX as one system.
- 🔤 **Fonts & Binary Workflows** — OTF/TTF metadata, archives, WOFF2 conversion and filesystem operations.
- 🖥️ **Desktop Engineering** — Electron, IPC, preload bridges, Windows integration and packaging.
- 🚀 **Production Mindset** — build, deploy, test, learn and iterate with real users.

# 🔤 Featured Product — FontFlow Pro

<div align="center">

### **The modern font workstation for designers, developers & type lovers.**

[![Open Website](https://img.shields.io/badge/🚀_Open_FontFlow-6366F1?style=for-the-badge&logo=googlechrome&logoColor=white)](https://fontflow.dpdns.org/)
[![Desktop](https://img.shields.io/badge/🖥️_Desktop-111827?style=for-the-badge&logo=electron&logoColor=white)](https://github.com/Ali-Mars/FontFlowPro)
[![Frontend](https://img.shields.io/badge/🌐_Frontend-0F172A?style=for-the-badge&logo=react&logoColor=61DAFB)](https://github.com/Ali-Mars/FontFlowPro-Front)
[![Backend](https://img.shields.io/badge/⚙️_Backend-111827?style=for-the-badge&logo=node.js&logoColor=68A063)](https://github.com/Ali-Mars/FontFlowPro-Back)

</div>

**FontFlow Pro is a complete font-management ecosystem:** a Windows desktop application, a public bilingual website, and a backend powering releases, downloads, support, bug reports, testimonials and update metadata.

### 🧰 What it can do

| Capability | Description |
|---|---|
| 🔎 Discover | Recursively scan font folders and supported archives. |
| 👁️ Preview | Live typography specimens before installing. |
| 🧬 Inspect | Font metadata, OpenType data and variable axes. |
| 🆚 Compare | Compare typefaces under consistent conditions. |
| 📂 Organize | Favorites, collections and font-library workflows. |
| ⚡ Load | Temporarily load fonts without permanent installation. |
| 💿 Install | Install supported fonts into Windows. |
| 🗑️ Manage | Uninstall and manage installed fonts. |
| 🔄 Convert | WOFF2 conversion for web workflows. |
| 🌐 Extract | Discover fonts used by websites. |
| 🎚️ Variable Fonts | Inspect and interact with font axes. |
| 🔠 Glyphs | Explore glyphs and character maps. |
| 🧪 Typography Lab | Test text, spacing, OpenType features and readability. |
| 🌍 Bilingual | Persian RTL + English localization. |
| 🔄 Updates | Website-backed release and update infrastructure. |

                                      │

              ▼                       ▼                       ▼
     ┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
     │   DESKTOP APP   │     │  PUBLIC WEBSITE │     │     BACKEND     │

     └─────────────────┘     └─────────────────┘     └─────────────────┘
              │                       │                       │

              │                       │                Bugs / Testimonials

| Repository | Role | Main Stack |
|---|---|---|
| [**FontFlowPro**](https://github.com/Ali-Mars/FontFlowPro) | 🖥️ Windows desktop application | Electron · React · Vite · OpenType.js · 7-Zip · WOFF2 |
| [**FontFlowPro-Front**](https://github.com/Ali-Mars/FontFlowPro-Front) | 🌐 Official product website | React · Vite · Tailwind CSS · Framer Motion · Axios |
| [**FontFlowPro-Back**](https://github.com/Ali-Mars/FontFlowPro-Back) | ⚙️ API + support infrastructure | Node.js · Express · MongoDB · Mongoose · Telegraf |

### 🌐 Official website

**https://fontflow.dpdns.org/**

The website includes `Features`, `Tutorials`, `Downloads`, `Version Details`, `FAQ`, `About / Contact` and `Terms`, with Persian RTL and English localization. It consumes live backend data for releases, download counters, bug reports, testimonials and update metadata.

> **FontFlow Pro manages fonts; it does not transfer font ownership rights.** Always follow the license/EULA of every font you install, extract, convert or redistribute.
